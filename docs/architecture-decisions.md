| Decision                        | Rationale                                             |
| ------------------------------- | ----------------------------------------------------- |
| Use Terraform                   | Enables repeatable Infrastructure as Code deployments |
| Use a dedicated VPC             | Provides network isolation                            |
| Use multiple Availability Zones | Improves availability                                 |
| Use an ALB                      | Provides traffic distribution and health checks       |
| Use private subnets for RDS     | Reduces direct exposure to the internet               |
| Use Security Groups             | Provides stateful network access control              |
| Use RDS                         | Reduces database management overhead                  |
| Use user data                   | Automates EC2 application installation                |
